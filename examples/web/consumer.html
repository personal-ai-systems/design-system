Pinned web consumer

This page imports the design system the way a website or dashboard would: a pinned package version, the variables file, and the optional default styles. Every colour, size, radius and duration below resolves from a token, not from this file.

What a consumer may assume

  • Loading variables.css alone changes nothing visually; it only defines custom properties.
  • base.css and components.css are optional and independent of each other.
  • Theme switching is an attribute: data-pas-theme="dark".
  • Values are provisional in 0.1.x, so the dependency is pinned to an exact version.
